# Ashen Shield

Java Swing fantasy character creation and turn-based combat application.

## Features

- Create a custom fantasy character
- Choose race, class, weapon and armor
- Allocate attribute points manually or randomly
- Normal and Hardcore difficulty modes
- Turn-based combat system
- Battle Log export
- Character save/load using serialization
- High Score system with multiple categories
- Swing-based graphical user interface

## Technologies

- Java
- Java Swing
- Object Serialization
- File I/O
- Object-Oriented Programming

## Project Structure

- app - application entry point
- gui - user interface panels
- model - game domain objects
- service - save/load and high score services
